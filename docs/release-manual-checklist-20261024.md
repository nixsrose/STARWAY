# STARWAY 출시 후보 수동 테스트

기준: v0.353 · 2026-10-24
자동 검사: 33/33 통과. 실제 기기 검수는 별도입니다.

온라인 점검표: https://starway-runner.nixsrose.chatgpt.site/release-checklist.html

## 순서

1. 설정 → 데이터에서 게임 백업을 보관합니다. 기존 저장 데이터는 삭제하지 않습니다.
2. 빠른 점검 22항목을 실제 기기에서 나누어 확인합니다.
3. 스토리 1-1~10-3을 실제로 완주하고 각 항로를 판정합니다.
4. 커버/메인 화면, 홈 전환/잠금, 동시 터치, 20분 플레이를 확인합니다.
5. 결과 파일 저장을 눌러 JSON 파일과 문제 구간 영상·진단 파일을 전달합니다.

## 각 항로 공통 기준

- 출발/조향/감속/점프가 정상 반응한다.
- 일반 터널 위 착지는 안전하고, 지지면이 없는 곳은 추락한다. 위험 표면은 폭발한다.
- 복잡한 구간에서 조작을 놓칠 정도로 끊기지 않는다.
- FINISH/메달/기록/보상/재도전/다음 항로가 정상 동작한다.
- 재실행 후 기록과 진행도가 유지된다.

## 출시 차단 기준

저장 손실, 진행 불가, 반복되는 잘못된 충돌은 해결 후 재검수합니다. 단일 자동 조작은 30개 중 9개를 완주했으며 나머지의 통과 불가를 입증한 것은 아닙니다. 모든 항로의 실제 완주 검수가 필요합니다.

Toss/Google Play 패키징, 플랫폼 계정·광고·결제 및 심사는 이 웹 검수와 별도입니다. 현재 생성된 Toss 배포 산출물이 없으므로 네이티브 출시 준비 완료로 판단하지 않습니다.
