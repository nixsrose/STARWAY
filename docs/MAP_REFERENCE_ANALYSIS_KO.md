# 참고 영상 관찰과 STARWAY 맵 구축
## 관찰 범위
사용자가 제공한 294503.mp4, 길이 약 10분 59.8초.
20초 간격으로 샘플 프레임을 추출하여 33개 지점을 비교했다.
아래 시각은 샘플 프레임 위치이며 해당 장면의 시작 시각이나 완전한 스테이지 경계가 아니다.
영상만으로 원작의 정확한 물리 수치, 전체 타일 데이터, 모든 코스 경계를 복원한 것은 아니다.

| 영상 위치 | 직접 관찰한 구조 | 새로운 코스에 적용할 역할 |
|---|---|---|
| 00:00 | 넓은 중앙 도로, 측면 분리 길과 벽 | 입문 조종, 장애물 회피 |
| 00:20 | 넓은 발판에서 분리된 길로 연결 | 폭이 바뀌는 구간 판단 |
| 01:20~02:00 | 다른 배경, 좁은 길과 끊긴 발판 | 저중력 도약, 착지 경로 |
| 02:20~03:20 | 평행 도로, 긴 틈, 좌우 경로 | 분기 선택과 이동 |
| 04:00~04:40 | 떨어진 좁은 길과 연결부 | 좌우 길 전환 |
| 05:00~06:00 | 중앙 통로, 양쪽 틈과 큰 벽 | 조종 우선의 통로 |
| 06:20~07:40 | 열린 길과 분리 길, 교대 구조 | 연속 판단과 회복 구간 |
| 08:40~10:20 | 좁은 도로, 구조물과 통로형 외형 | 복합 코스. 터널 형상 자체는 이번 구현에서 제외 |
| 10:40 | 반복되는 체크무늬 바닥 | 시각 테마의 차별화 |

핵심은 색상만 변경하는 것이 아니라 길 폭, 단절, 분기, 회복 구간이 만들어내는 판단을 달리하는 것이다.
원작 자산과 지도를 복제하지 않고 관찰한 플레이 역할을 새 코스로 구성했다.

## 인터페이스와 물리
- 중력: 코스에서 지정, 사용자가 변경하지 않음. 점프 초기속도 7.8, 체공시간 약 2×7.8/중력. 중력 11은 약 1.42초, 27은 약 0.58초.
- 속도: 목표값 6~22m/s. 모바일 +/− 버튼 또는 키보드 ↑/↓로 조절. 목표 속도는 유지되고 실제 속도는 부드럽게 접근한다. HUD는 기존 표시배율 ×28 유지.
- 연료: 초당 소모량 = 0.4 + 0.011×실제속도². 속도 6에서는 약 0.8%, 22에서는 약 5.72%/초.
- 생명: 체력 수치가 아닌 남은 제한시간. 스토리 제한시간은 ceil(도로 길이/9+16)초. 일시정지·광고 중 감소하지 않음.
- 무한 모드: 시작 시간 75초, 180m 층 통과마다 18초 추가, 최대 90초. 속도는 사용자가 조절하며 난도는 도로 구조·중력·연료 빈도로 증가.
- 부활: 안전한 이전 구간에서 재개, 속도 6, 연료 최소 50%, 남은 시간 최소 20초.

## 검사와 남은 검증
18개 스토리 코스를 자동 조종으로 기본 속도에서 완주했다.
고정 맵, 코인 분포, 단일 연료칸, 중력·연료·시간·일시정지·가감속, 기존 추락·폭발·수익화 흐름을 검사했다.
이는 실제 플레이 재미, 모바일 가독성, 모든 속도에서의 모든 경로 완주를 보증하지 않는다.
실제 모바일 플레이 피드백으로 시간·연료·점프 간격을 추가 조정해야 한다.

## 반복감 개선 적용
이전의 36m 고정 주기를 제거했다. 18개 코스마다 직접 지정한 서로 다른 순서를 사용하며 구간 길이는 20~58m로 다양하다.
전체 코스 길이는 286~428m. 같은 타입을 넣더라도 구간 길이와 진입 측면, 앞뒤 연결을 달리한다.
총 13종의 구간: 넓은 진입로, 수축하는 길, 중앙 벽 우회, 단절된 항로, 대각선 연결로, 충전 휴식 구간, 좌우 분리 도로, 가속 패드, 감속 패드, 교차 발판, 낮은 터널, 독립 발판, 분기와 합류.
- 중앙 높은 벽: 높이 2.2로 점프보다 좌우 우회를 요구한다.
- 대각선 연결로: 넓은 구간 사이에서 좁은 연결로를 따라 조종한다.
- 교차 발판: 안전 차선 옆에 구멍과 블록이 교대하며 경로를 읽게 한다.
- 낮은 터널: 천장 1.15. 기체 높이를 포함해 점프 중 천장에 닿으면 충돌 폭발.
- 가속 패드: 2초간 목표 속도에 +4, 최대 24. 실제 속도에 따른 연료 소모 적용.
- 감속 패드: 1.5초간 목표 속도 ×0.65, 최소 6.
- 휴식 구간: 좁은 길 뒤 넓은 길에서 경로를 다시 정하고 연료를 보충한다.
스토리는 고정 데이터, 코인 위치도 고정. 스킨 구매/진행도 저장은 그대로 유지한다.
18개 코스 기본 속도 완주, 터널 천장 충돌, 높은 벽 충돌, 가속/감속, 구간 길이 다양성, 맵 중복 없음 검사를 통과했다.
실제 Canvas로 중앙 벽, 대각선, 독립 발판, 분기, 터널, 교차 발판 6개 장면을 렌더링해 구조 차이를 확인했다.
모바일 브라우저 UI와 실제 조작감은 별도 검증이 필요하다.

## 난이도·터널·박스 착지 판정 수정
영상 약 09:27 이후의 둥근 터널 입구를 다시 확인했다. 기존 프레임 아치를 연속된 곡면 지붕과 입구 테두리를 갖춘 원통형 구조로 변경했다.
벽은 기체 중심 |x|>1.2에서 충돌, 둥근 천장 높이는 중심에서 1.15이고 측면으로 갈수록 낮아진다.
첫 번째 코스에도 짧은 터널을 추가했다.
박스 상면 높이 0.85, 높은 벽 2.2에 착지할 때 기체가 폭발하도록 접촉 여유값과 하강 상면 교차 판정을 적용했다. 박스 자체가 파괴되는 보상 오브젝트로 바꾼 것은 아니다.

| 난이도 | 중력 배율 | 연료 소모 배율 | 제한시간 배율 | 구조 변경 |
|---|---:|---:|---:|---|
| 쉬움 | 0.9 | 0.7 | 1.4 | 좁은 구간의 안전 경로 주변 일부 확장 |
| 보통 | 1 | 1 | 1 | 원래 고정 코스 |
| 어려움 | 1.12 | 1.4 | 0.8 | 넓은 구간의 경로 주변에 추가 장애물 |

같은 난이도와 코스는 재도전해도 같은 배치. 난이도 선택을 저장하고 HUD에 표시한다.
어려움의 추가 장애물은 대각선·단절 구간의 착지 경로를 막지 않도록 제외한다.
18코스 × 3난이도 = 54개 참조 경로를 기본 속도로 완주했다.
박스 상면 착지 폭발, 난이도별 맵/수치 차이, 선택 저장, 터널 전후 Canvas 렌더를 검사했다.

## 사용자 의도 정정: 스테이지 자체의 난도
쉬움/보통/어려움 선택과 그 수치 배율을 제거했다. 기존에 저장된 선택값도 게임 동작에 사용하지 않는다.
난도는 18개 코스의 고정 경로, 분기, 폭, 점프·터널·장애물 조합으로 결정한다. HUD의 항로 순서는 플레이 진행 위치이며 난도 측정값은 아니다.
구간 앞뒤가 매번 중앙의 5차선 직선으로 되돌아가는 구조를 제거했다. 이전 구간의 끝과 다음 구간의 시작을 점진적으로 연결하여 도로 중심이 좌우로 이동한다.
초반 3코스는 연결 폭 1.1, 이후 코스는 0.85 범위를 기준으로 도로 타일을 구성한다. 분기·합류와 휴식 공간은 필요한 폭을 유지한다.
모든 코스에 한 갈래에서 두 갈래로 나뉘는 분기 구간을 포함하고, 재도전 시 같은 경로와 코인 배치를 유지한다.
18코스 기본 속도 참조 경로 완주, 모든 코스 좌우 이동 및 분기 존재 검사 통과. 실제 플레이 난도와 학습 곡선은 모바일 플레이로 조정해야 한다.

## 1라운드: Red Heat Road 1 참고 코스

전체 220m, 기존 게임 코인/연료 시스템 유지. 원작의 정확한 타일 배열과 속도를 추출한 복원본이 아니라 관찰한 구간 순서와 형태에 맞춘 재구성이다.

박스 상면 착지와 유지, 재점프, 내려오기, 옆면 폭발, 18코스 참조 경로 완주 검사 통과.
첫 코스 진입부와 쌍터널 장면을 실제 Canvas로 렌더링해 확인했다. 실제 모바일 플레이 검증은 남아 있다.

## 무한 모드 연료 수지 수정
이전 설정: 후반 최대 600m 간격, 22% 충전. 모두 획득해도 장기적으로 소진되는 구조였음.
현재 무한 모드: 40% 충전, 간격 60m → 90m → 120m. 120m 상한 유지. 한 칸 패드는 그대로.
연료 패드는 30m 블록의 24번째 행인 회복 구간에만 배치. 간격도 30m 배수여서 생성 지연으로 최대 간격이 초과되지 않음.
최대 실제속도 24에서는 120m 동안 약 33.68% 소비하므로 충전 40%보다 작다. 높은 속도의 높은 소모는 유지한다.
층 통과 시간 보충은 18초에서 30초로 변경. 최저 속도 6에서 180m/6=30초이므로 꾸준히 진행하면 제한시간도 구조적으로 소진되지 않는다.
속도 6/10/16/22/24 각각 20,000m 연료 수지 시뮬레이션 통과. 연료·시간 리셋 없이 실제 픽업 로직으로 검사했다.
해당 수지 검사는 장애물과 구멍을 제거하고 패드 위치에 맞춰 조종하여 충전 수지만 독립 검증했다. 모든 속도에서의 장애물 회피 또는 실제 플레이 무한 생존을 보증하지 않는다.
연료 미획득 시 소진, 한 패드 중복 충전 방지 검사 통과. 스토리 모드의 22% 충전은 유지한다.

## 나머지 17코스의 1-1 수준 구성 적용
1-1의 별도 항로 데이터는 유지하고, 1-2~6-3도 7열 도로로 변경했다. 중앙/측면 도로 사이에 빈 공간을 두고 가끔 교량으로 연결한다.
기존 코스별 구간 순서와 난도는 유지하면서 분리 항로, 중앙 박스, 단일 및 이중 터널을 각 코스에 맞춰 배치했다.
이중 터널 코스는 각각 별도 천장·중심 좌표를 가지며 실제 충돌 판정도 이에 맞춘다.
각 코스에 고유 제목 부여. 배경은 Red Heat 계열 태양, 달 분화구, 화성/소행성, 목성 띠, 토성 고리, 심우주 파편으로 구분한다. 모두 코드로 생성한 표현.
코인과 연료 배치는 새 도로의 유효한 바닥에 맞춰 조정했고, 재도전 시 고정된다.
18코스 기본 속도 자동 완주 및 기존 박스/추락/광고 보상/연료 검사 통과. 6개 대표 코스를 실제 Canvas로 렌더링해 차이를 확인했다.
원작의 나머지 코스 타일을 정확히 복원한 결과는 아니다. 1-1 수준의 공간 구성과 표현을 적용한 STARWAY 고정 코스들이다.

## 구조물의 기체 가림
기존에는 기체를 항상 마지막에 그려 터널 지붕과 박스를 투과해 보였다.
