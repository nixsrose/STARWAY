## 검토 대상

- 7-1: 데이터 기준92~119행(에디터93~120줄)은 중앙 한 칸 도로에 연속28칸 위험 바닥이며 좌우는 틈이다. 이 구간에는 터널·다리·중력 게이트가 없고 앞쪽에 가속 패드도 없다. 기본 스카우트의 평지 실측 점프 거리는 중력50·속도15.4에서22.33칸이다. 이 직선 도약 구간은 기본 성능과 길이가 맞지 않는다. 강화 필수 구간으로 둘지, 위험 길이를 줄이거나 중간 안전 발판을 둘지 결정할 필요가 있다.

- 9-2: 중력150. 기본 점프 최고 높이 실측0.767, 블록 높이0.85. 바닥에서 바로 블록 위로 점프하는 기존 안내 경로는 높이가 부족하다. 단절된 측면 도로를 활용하는 전체 우회 경로는 이번 시험에서 완주하지 못했다. 전체 맵이 불가능하다고 확정하지 않는다. 우회로 연결과 기본 능력 기준을 함께 검토해야 한다.

## 해석

- 2-2·2-3·4-2·4-3·5-3·7-3은 기존 guide를 따르는 방식 외의 경로 탐색으로 완주했다. 이는 저장된 guide만으로 통과 가능성을 판단하면 안 된다는 증거다. guide가 실제 플레이에 자동 조종으로 사용되는 것은 아니다.
- 5-2·6-3 등은 1차 표본에서 성공한 설정 수가 적었다. 이를 정확한 입력 허용 폭이나 사람의 성공률로 해석하지 않는다.
- 별도 외부 테스트가 필요하다. 7-1·9-2는 기본맵의 조정 후보이며 사용자 기기의 편집 맵에는 다른 결과가 날 수 있다.
