# Acceleration pad — v0.360

Ground contact with tile 4 immediately sets the actual run speed to 800 km/h (800/36 internal units), bypassing the hull's normal speed cap for three simulation seconds. Speed stays at 800 during the boost; expiry immediately returns to the currently selected throttle target capped by the normal hull performance. The lever remains the player's normal speed setting. This changes movement and fuel use, not only the HUD number.

Another acceleration-pad row refreshes the three-second duration. Pause freezes the timer. A slow pad cancels the boost and applies the existing slowdown. Acceleration clears an existing slowdown. Retry/revive retain their existing timer resets. No map data is changed. Gauge maximum includes the 800 km/h boost value.

Validation: boost-pad checks immediate activation, duration boundary, movement distance, throttle return, pause, refresh, slowdown priority and retry. Current full release gate recorded in release-audit.md. No physical device verification performed in this change.
